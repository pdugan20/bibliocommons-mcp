These are the tools an MCP client can call. Each is marked **read-only**,
**writes** (creates account state), or **destructive** (not trivially
reversible) from its MCP annotations, so clients can decide when to confirm.
See [Install](/install) for setup and [Recipes](/guides/recipes) for prompts.


## Read-only

### `availability`

**Read-only.** Show per-branch copy status for a bib.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `bib_id` | string | yes |  |

### `library_health`

**Read-only.** Verify login + report hold counts vs. caps.

_No parameters._

### `list_branches`

**Read-only.** List every branch with its library-specific pickup code.

_No parameters._

### `list_holds`

**Read-only.** Show current holds (physical + digital) with queue positions.

_No parameters._

### `list_loans`

**Read-only.** Show current checkouts (physical + digital) with due dates.

_No parameters._

### `ready_for_pickup`

**Read-only.** Show only the holds that have arrived at the user's pickup branch.

_No parameters._

### `search`

**Read-only.** Search the catalog by keyword, optionally filtered by format.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `query` | string | yes |  |
| `format` | string | no |  |
| `page` | integer | no |  |
| `sort_by` | string | no |  |


## Writes

### `borrow_digital`

**Writes.** Check out one or more immediately-available digital items.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `bib_ids` | string[] | yes |  |
| `delay_seconds` | number | no |  |

### `check_in_loan`

**Writes.** Return one or more digital checkouts (ebook / eaudiobook) early.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `checkouts` | object[] | yes |  |
| `dry_run` | boolean | no |  |
| `delay_seconds` | number | no |  |

### `place_digital_hold`

**Writes.** Join the Libby-side waitlist for one or more unavailable digital items (`availableCopies: 0` on the bib).

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `bib_ids` | string[] | yes |  |
| `delay_seconds` | number | no |  |

### `place_hold`

**Writes.** Place a physical hold on one or more bibs at the same pickup branch.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `bib_ids` | string[] | yes |  |
| `pickup_branch` | string | no |  |
| `delay_seconds` | number | no |  |

### `renew_loan`

**Writes.** Renew one or more physical checkouts in a single gateway call.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `checkout_ids` | string[] | yes |  |
| `dry_run` | boolean | no |  |
