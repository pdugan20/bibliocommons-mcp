**bibliocommons-mcp** connects an MCP client (Claude Desktop, Claude Code, the
Claude mobile app, Cursor, …) to a **BiblioCommons-powered public library** so
you can search the catalog, place and cancel holds, borrow and return digital
titles, and manage your loans, all in plain language.

It works against **any BiblioCommons library** (tested with `seattle` and
`sfpl`); you pick yours by subdomain. Run it two ways:

<CardGroup cols={2}>
  <Card title="Locally (stdio)" icon="laptop" href="/quickstart">
    Install it and point Claude Desktop / Claude Code at it. Your card and PIN
    stay on your machine.
  </Card>
  <Card title="As a remote connector" icon="globe" href="/guides/self-host-remote">
    Self-host it over HTTPS and add it as a custom connector, usable from the
    Claude mobile app. OAuth-gated; single-user.
  </Card>
</CardGroup>

## How it works

bibliocommons-mcp is a thin, stateless proxy over the public BiblioCommons
gateway (`gateway.bibliocommons.com`). One server instance talks to one library,
configured by subdomain. See [Architecture](/concepts/architecture) for the
design and [Configuration](/reference/configuration) for every setting.
