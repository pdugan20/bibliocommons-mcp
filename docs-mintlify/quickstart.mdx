This gets you from zero to "search the catalog from Claude" locally. For other
clients see [Install](/install); to run it on your phone see
[Self-host the remote connector](/guides/self-host-remote).

## 1. Install

Requires **Python 3.11+**.

<CodeGroup>
```bash uv
uvx bibliocommons-mcp --version
```

```bash pipx
pipx install bibliocommons-mcp
```

```bash pip
pip install bibliocommons-mcp
```
</CodeGroup>

This provides the `bibliocommons-mcp` command.

## 2. Configure your library + card

Run the interactive wizard:

```bash
bibliocommons-mcp init
```

It writes `~/.config/bibliocommons-mcp/config.toml` (mode `0600`) with your
**library subdomain**, **card number**, and **PIN**. You can also set these via
environment variables — see [Configuration](/reference/configuration).

<Note>
  Your library subdomain is the first part of your catalog URL — e.g.
  `seattle` for `seattle.bibliocommons.com`, `sfpl` for San Francisco.
</Note>

## 3. Connect it to Claude Desktop

Add it to `claude_desktop_config.json`
(macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "bibliocommons": { "command": "bibliocommons-mcp", "args": [] }
  }
}
```

Restart Claude Desktop. (Using Claude Code or another client instead? See
[Install](/install).)

## 4. Try it

Ask Claude:

> Search the catalog for "Plastic Eternity" on CD and tell me which branches have it.

Claude will call [`search`](/reference/mcp-tools) and
[`availability`](/reference/mcp-tools). When something seems off, ask it to run
**`library_health`** first — that confirms login + your hold quotas.
