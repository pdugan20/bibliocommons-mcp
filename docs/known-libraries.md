# Library compatibility

The same gateway endpoints serve every BiblioCommons-powered library; most should work. This page tracks what's been verified.

| Library                      | Subdomain | Status     |
| ---------------------------- | --------- | ---------- |
| Seattle Public Library       | `seattle` | end-to-end |
| San Francisco Public Library | `sfpl`    | read-only  |

Status definitions:

- **end-to-end** — search, holds, and cancel verified against a live account
- **read-only** — search and availability verified; holds untested

Tried yours? [Open a compatibility report](https://github.com/pdugan20/bibliocommons-mcp/issues/new?template=library_compatibility.yml). "Works fine" reports are as useful as bug reports.
